# Regras dos agentes neste projeto

Este projeto usa o INEMA Agent Runtime. Antes de agir, leia:

1. `runtime/POLITICA.md`: o que você faz sozinho, o que pede antes e o que nunca faz.
2. `runtime/CAPACIDADES.md`: só use sistemas listados ali, pela via indicada.
3. `runtime/ROTEAMENTO.md`: use o menor modelo que resolve.

Antes de dizer que algo é impossível, suba a escada de vias do `runtime/LEIA-ME.md` e teste cada nível com um comando.

Você não muda estas regras. Para propor uma mudança, acrescente uma linha na tabela "Aprendizado" da `runtime/POLITICA.md`. Quem aprova é o humano.
